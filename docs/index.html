Software Engineering Buddy

A CLI coach that tells you exactly what to do next in your project's lifecycle— from planning and prototyping to CI/CD and security scanning.

Stop guessing. Run one command. Get a health score and a step-by-step roadmap.

See Your Score View on GitHub

5-Stage Roadmap

Planning, Setup, Code Quality, DevSecOps, and Deployment. It knows what order to do things in.

Auto-Fixer

Missing a CI pipeline or a secure Dockerfile? One command generates it for you.

Secret Scanner

Finds hardcoded passwords and API keys before you accidentally commit them.

How it works

1. Scan your repo
java -jar sebuddy.jar check .
→
2. Fix what's missing
java -jar sebuddy.jar fix ci-exists .
→
3. Get your next step
java -jar sebuddy.jar next .

Optional: Add --json to your check command to export a report, then upload it below for a visual dashboard.
